# 现有四个报告任务的 Stock 增量

此文件是供现有任务追加的研究契约，不会创建、启动或重配任务。原有风险预算、全资产名额、稳定 idea_id 与归档协议继续适用。

## 通用模块

使用 farfromexact/China-Stock-Engine 为研究提供公司经营与盈利质量证据、商品利润传导、股指和风格验证。Stock 候选是研究线索；公司证据可以推翻既有宏观或商品观点。A 股与其他资产竞争原榜单名额，最多深入展示 3 家，可为 0 家。

固定同一 commit/ref，记录交易日期、研究截点和输入版本。依次读取 last_run_status、latest/manifest、data_reference 的 research_context/research_capabilities、紧凑 opportunity_radar；按需沿 research_inputs 的实际 shards 索引读取候选分片并验证 hash。不要默认加载全市场大文件。区分 missing、empty、truncated、parse_error、stale 和权限失败；工具未返回正文不等于源文件为空。

data_fresh 或分片生成完成不等于全部能力就绪。分别检查原始/复权多周期收益、行业、真实指数成分、财务、公告、预测及证券状态。今天允许使用研究截点前补齐并验证的事实，但不能声称历史决策时点已掌握。候选池不能推断全市场宽度，市值代理不能冒充指数成分。

对深入研究的每家公司回答：实质变化是什么；当前价格可能反映什么及依据；与市场的分歧是什么；什么新增证据最能区分主假设和竞争解释；催化如何及何时改变盈利或定价；什么事实会证伪；为何股票优于行业 ETF、股指、商品或不交易。

同一价格序列的多个指标不是独立基本面证据。公告数量不等于催化强度，同比增长不等于超预期，低 PE 不等于便宜。财务注明报告期、YTD/单季/TTM、发布时间和一次性因素，核对业务类型适用性；缺一致预期时使用情景和估值隐含条件。原始公司披露优先，媒体摘要和上期生成文字不能替代原始事实。

只有重点商品或深研公司需要时才读取 commodity_exposures。分别核对售价、原料成本、销量、库存、套保、资本开支和体现时间；未知或 research_only 暴露不能当作确定利润敏感度。比较股票与直接商品表达的依据、条件和风险。

延续稳定 idea_id，记录证据带来的方向、排序、表达或风险变化，或注明仅作背景。没有新证据不制造观点变化。区分已研究无优势、存在待验证机会、数据不足。分别列研究判断、证据充分程度和执行状态；EOD 不是当前可成交报价。无可靠证券状态、报价和交易参数不得称可执行；无盘中路径和成交反馈不得假设触发、模拟成交或真实持仓。交易制度、下一可交易窗口、成本、流动性和涨跌停另行核验，止损不保证最大损失。

研究过程只读 Stock，不触发采集或修改配置。结果依原有 Radar 归档协议保存，不创建另一套台账。

## 四个任务的职责

| 任务 | 追加职责 |
| --- | --- |
| Global Opportunities Morning | 检验最近完整 A 股 EOD 后的公开公司信息及隔夜变化，复核旧观点；旧收盘价不能与新增消息拼成已确认价格反应。 |
| Global Opportunities Evening | 复核最新可用 EOD 与公司证据是否一致；新增证据足以影响未来决策才调整排序，不以当日涨跌追认观点正确。 |
| Commodities Opportunities Morning | 对重点商品假设核对公司利润暴露和股票表达，不再完整扫描全市场。 |
| Commodities Opportunities Evening | 核对价格、价差、事件是否改变已有公司假设；商品日内上涨不能直接换算成公司利润增长。 |

早晚复核可以重复，已经验证的底表不重复采集。20 日影子比较关注有效新证据、反证、表达选择和不可执行建议减少，不能只数新增股票，也不能据此认定策略有稳定超额收益。
